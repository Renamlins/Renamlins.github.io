# Projetos em destaque

## 📊 Sales Performance Analytics

**Oracle SQL • ERP WinThor • Business Intelligence**

Projeto de Data Analytics aplicado à gestão comercial, desenvolvido para consolidar dados de vendas, clientes, carteira e financeiro em uma visão gerencial.

Entre os indicadores analisados:

- projeção de vendas;
- churn;
- reativação de clientes;
- cobertura de carteira;
- margem;
- inadimplência.

A principal camada do projeto é construída em **Oracle SQL**, utilizando regras de negócio e dados provenientes do ERP WinThor.

➡️ **[Ver estudo de caso](https://renamlins.github.io/sales-performance-analytics-oracle/)**
